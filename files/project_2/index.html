About the project

As part of a healthcare sector initiative, I created comprehensive user documentation for prostate cancer treatment software, tailored specifically for medical personnel, there was major change in desing of interfaces. The work involved creating documentation and redesigning software interfaces to make the application more user-friendly in a clinical environment, without the need to involve service providers.

🎯 Goals

  • Deliver safe software for clinical use.
  • Maintain compliance with medical standards and requirements.
  • Use instructions to train clinical users and hospital staff.
  • Create consistent content across different clinical teams and environments.
  • Organize content so that the structure allows for easy editing of the existing document in the future when the software changes.

⏳ Process - new approch

  • Step-by-step instructions to guide clinicians through the software
  • Create user interface overviews to help users navigate efficiently.
  • Aligned documentation with risk management processes and regulatory requirements.
  • Collaborate with subject matter experts (SMEs), such as clinical users, risk managers, and regulatory specialists.
  • Design the structure of the document.
  • Use clear, unambiguous language to reduce the chance of misinterpretation in critical clinical setting.
